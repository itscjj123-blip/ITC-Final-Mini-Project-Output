REQUIRED FEATURES CHECKLIST
  - Doctype, html, head, title, body, viewport meta on every page
  - Semantic regions: header, nav, main, section, article, footer
  - One h1 per page, then h2 / h3
  - Working nav; current page marked with aria-current and styling
  - Contact form: label, text, email, select, textarea, button;
    required on name and email; labels match inputs (for/id)
  - figure + figcaption on images; audio element with controls and a text label
  - CSS variables for colors and fonts; Flexbox and Grid both used
  - Breakpoints at 768px (tablet) and 1024px (desktop); phone is the base
  - Hover and focus states on links, buttons and form fields
  - Contact form posts to the free FormSubmit service, which emails each
    message to the address in the form action line in contact.html.
    The first message sent triggers an activation email that must be
    confirmed once. It only works from a hosted site, not from a file
    opened on the computer.
  - JavaScript: none (optional and not graded)

TOOLS
